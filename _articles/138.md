Lors de notre visite à Rennes chez Gaël, et aussi à la visite de quelques magasins, nous sommes tombés devant des boites [3420](http://guide.lugnet.com/set/3420) Version France.  
La question est rapidement venue Minifig avec sticker ou imprimée.

Je vais essayer de tout vous dire sur les minifigs de cette boite.

## Préambule

En préambule, il faut prendre en compte les points suivants :

**–** Chez LEGO une minifig est principalement constitué de deux pièces et non trois comme chez bricklink et peeron :

-   **Le buste et la tête**

-   -   Le buste et la tête ont un code générique LEGO qui est le 73403. Ce code est toujours le même que le buste soit de couleur unis ou sérigraphie
    -   Chaque buste est après assortis d’un numéro informatique qui permet à LEGO de faire sa gestion de stock.
    -   Ce code au début des minifig (1978) était un code à 5 chiffres 73834 pour la Minifig 1, puis ce code est passé à la structure actuelle sous la forme 4.. .. ..
    -   Chaque buste ainsi constitué à de plus un numéro de montage.  
        la série à débutée à 1 et va bientôt passer les 900.

-   **Les Jambes**
    -   Les jambes ont un code générique LEGO qui est le 73200.  
        Ce code est toujours le même que les jambes soient intégralement de la même couleur, constitué de jambes et ceinture de couleurs différentes, ou même sérigraphie
    -   Comme les bustes les jambes sont assortis d’un numéro informatique.
    -   Ce code au débuts des minifig (1978) était un code à 4 chiffres 9327 pour les jambes toute blanche, puis ce code est passé 5 chiffres et enfin à la structure actuelle sous la forme 4.. .. ..
    -   Chaque jambes ayant reçu une sérigraphie est assortis elle aussi d’un numéro d’ordre ayant débuté à 1.

## Seconde Sortie

La boite 3420 est sortie une seconde fois en France avec deux équipes de 5 joueurs et deux gardiens de but.  
Une équipe Rouge et Blanche et une équipe Bleu et Blanche.

## Equipe Rouge et Blanche

Cette équipe est exactement la même que dans la première version de la boite.

## Equipe Bleu et Blanche

Cette équipe est constitué de joueurs aux couleurs de l’équipe de France.
