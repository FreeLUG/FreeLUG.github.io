## Premiéres Impressions

Cette nouvelle série (8441,8451 et 8453) de modèles Technic me fait penser â la série des Mini StarWars. En effet ces modêles sont à une échelle bien moindre que celles qu’on a l’habitude de rencontrer dans les modèles Technic (échelle qui est au moins celle des minifigs technic).

A noter : la présence sur la boite de l’inventaire du contenu. ceci semble être une nouveautés qui devrait se généraliser sur les boites Technic. Cela permet de savoir facilement ce qu’on achète.

## Intérêts

Ce set permet de faire 2 modèles :  
**–** le chariot élévateur a fourche : rien de bien extraodinaire dans ce modèle. l’élevation se fait par un vulgaire elastique (rien de bien technique). D’ailleurs l’élévation est tellement "élastique", que si l’on met un objet sur la fouche, celui-ci est envoyé tres haut :-). Il n’y a pas de direction dans ce modéle et, à dire vrai, rien de technic qui mérite notre attention.  
**–** une voiture à suspensions : évidemment ce modèle n’est pas exceptionnel non plus. la voiture n’a pas de direction non plus. la suspension est faite avec le même élastique que l’élévation du modèle précédent. c’est le seul détail technic de ce modèle.

## Conclusion

Avec un prix par pièce de 0,12 euros, cela semble être le seul interêt (et encore) de ce set. Les roues ne sont pas réutilisable dans un set technic (dans le sens ou il n’est pas possible d’insérer une barre dedans) et il n’y a aucun engrenage. Bref un set d’entrée de gamme, pas cher et qui peut faire un petit cadeau sympathique. mais les fans de technic ne vont pas se ruer dessus.
