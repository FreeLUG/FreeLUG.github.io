Installation de MLCAD sous Windows (instructions tirées du site [www.ldraw.org](http://www.ldraw.org/)

**Etape 1 :**  
Télécharger [ldraw027.exe](http://www.ldraw.org/download/start/win/step1.shtml) et [complete.exe](http://www.ldraw.org/library/updates/)

**Etape 2 :**  
Pour les installations et pour une question de commodité, je crée un répertoire ...\\lego où je retrouve tous les programmes qui concernent les briques Lego®.

Créer un répertoire c :\\lego, et copiez-y ldraw027.exe et complete.exe. Aller dans le menu Démarrer/Exécuter... et taper **c :\\lego\\ldraw027.exe -y** puis refaite la même opération avec **c :\\lego\\complete.exe -y**

Dans le répertoire ...\\ldraw se trouve le fichier parts.lst, supprimer-le. C’est la base de données des pièces, mais qui est recrée automatiquement et proprement lors de la première ouverture de MLCAD, c’est recommandé.

**Etape 3 :**  
Télécharger [MLCAD](http://lm-software.com/mlcad/)

Créer un répertoire c :\\lego\\mlcad , et installer MLCAD dans le répertoire ...\\mlcad.

Une fois installé, lancer le programme, il vous demandera de donner le chemin de Ldraw et il mettra à jour sa base de données (parts.lst).
