Traduction des règles des courses de "RailRacers"

Le document original est disponible à [www.railracers.com](http://www.railracers.com/)

**Catégorie Monomoteur Non Modifié**

|  |  |
| --- | --- |
| Taille | 48 tenons (l’équivalent de 3 rails) ou moins |
| Motorisation | Un moteur de train d’origine |
| Personnel | Au moins un pilote |
| Matériel roulant | Le véhicule de course doit se composer d’un moteur et d’un boggie. Le moteur peut être placé aussi bien à l’arrière qu’à l’avant. Les deux peuvent être assemblé comme bon vous semble mais il doivent rester couplé tout au long de la course. |
| Pièces | Le véhicule doit être fabriqué à partir de pièces Lego d’origine |

**Catégorie Multimoteur Non Modifié**

|  |  |
| --- | --- |
| Taille | 48 tenons (l’équivalent de 3 rails) ou moins |
| Motorisation | N’importe quel nombre de moteur de train d’origine |
| Personnel | Au moins un pilote |
| Matériel roulant | Le véhicule de course doit se composer de deux sous-ensembles couplés comme bon vous semble. Chacun de ces sous-ensembles comporte un ou deux moteurs. |
| Pièces | Le véhicule doit être fabriqué à partir de pièces Lego d’origine |

**Catégorie Monomoteur Modifié**

|  |  |
| --- | --- |
| Taille | 48 tenons (l’équivalent de 3 rails) ou moins |
| Motorisation | Un moteur de train modifié |
| Personnel | Au moins un pilote |
| Matériel roulant | Le véhicule de course doit se composer d’un moteur et d’un boggie. Le moteur peut être placé aussi bien à l’arrière qu’à l’avant. Les deux peuvent être assemblé comme bon vous semble mais il doivent rester couplé tout au long de la course. |
| Pièces | Le véhicule doit être fabriqué à partir de pièces LEGO® d’origine mais peut contenir jusqu’à 50¨% de pièces LEGO® modifiés ou de pièces non-LEGO®. Il doit rester en mesure de rouler sur des rails LEGO® d’origine.L’utilisation de produits combustibles est interdit. |

**Catégorie Multimoteur Modifié**

|  |  |
| --- | --- |
| Taille | 48 tenons (l’équivalent de 3 rails) ou moins |
| Motorisation | N’importe quel nombre de moteur de train modifié |
| Personnel | Au moins un pilote |
| Matériel roulant | Le véhicule de course doit se composer de deux sous-ensembles couplés comme bon vous semble. Chacun de ces sous-ensembles comporte un ou deux moteurs. |
| Pièces | Le véhicule doit être fabriqué à partir de pièces LEGO® d’origine mais peut contenir jusqu’à 50¨% de pièces LEGO® modifiés ou de pièces non-LEGO®. Il doit rester en mesure de rouler sur des rails LEGO® d’origine.L’utilisation de produits combustibles est interdit. |

_Ces règles sont les seules règles officielles édictées par l’association "Rail Racers™"._

_Ces règles doivent prévaloir contre tout autres règles s’y opposant concernant une course "Rail Racers™"_

_Ces règles sont sujettes à modifications par décision de l’association "Rail Racers™"._

_Dans l’éventualité d’une modification des règles, les règles à appliquer au cours d’une course sont celles qui étaient officielles le matin du jour de la course._
