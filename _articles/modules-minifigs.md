Caractéristiques des modules pour la présentation des minifigs.

## Objet

Cette article a pour objet de décrire les caractéristiques de modules destinés à présenter les minifigs. Ceci doit permettre de créer des modules indépendants, objet d’un thème, afin de pouvoir les rassembler à l’occasion de rassemblements ou d’expositions.

Cette description ainsi que [les modules photographiés](http://www.brickshelf.com/cgi-bin/gallery.cgi?f=53866) sont l’oeuvre de Denis (CDHD).

Vous pouvez aussi consulter sur [http://www.minimundo.de/](http://www.minimundo.de/) une collection de minifig qui a inspiré l’idée de ces modules.

## Taille du module

Le module a pour support une **plaque de base 16x32** à coins carrés.

Sa **hauteur est de 18**.

La face avant est entièrement ouverte. La face arrière, fermée, peut être partiellement ouverte.

Les côtés présentent le gabarit que vous trouverez en lien afin que le module soit à la fois rigide (pour permettre l’empilement) et permette l’alignement en enfilade :

En rouge le profil minimum.  
En gris le gabarit maximum.

[<IMG SRC="http://www.brickshelf.com/gallery/dickydidier/modules/thumb/gabarit.jpg\_thumb.jpg">](http://www.brickshelf.com/gallery/dickydidier/modules/gabarit.jpg)

Le module doit présenter un minimum de 7 figurines.

Tous les autres éléments sont libres : couleurs, thème (espace, western, ville,...), présentation intérieur (gradins, diorama,)...
