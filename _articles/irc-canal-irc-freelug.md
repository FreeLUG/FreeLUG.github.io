Le canal ou salon IRC #freelug est un moyen rapide pour discuter entre passionnés de la petite brique. Nul besoin d’inscription, ce peut être pratique si vous avez une question. C’est également un lieu d’échange instantané des derniers potins.

D’une façon générale, un écran IRC se divise en trois parties :  
**–** une zone de saisie pour écrire ses messages ;  
**–** une zone où sont affichés tous les messages échangés ;  
**–** la liste des personnes connectées.

Le canal #freelug est hébergé sur le réseau [freenode](http://freenode.net/).

Il existe deux façons de se connecter à IRC sur le canal #freelug.

## IRC via la page web

Ne nécessitant aucune installation, c’est le moyen le plus simple pour se connecter à IRC.

[Se connecter à IRC via l’interface web](https://freelug.org/cgi-bin/cgiirc/irc.cgi). Le lien est également disponible depuis la première page du site.

Il vous suffit de choisir un pseudo.

Toutefois, selon la configuration de votre connexion, ce mode peut plus ou moins bien fonctionner. Nous vous conseillons alors de passer par un vrai client.

## IRC via un client IRC

Moyen le plus sûr et le plus fiable pour se connecter à IRC, l’usage d’un client apporte plus de confort que l’interface web.  
**–** serveur : irc.freelug.org  
**–** canal : #freelug

Vous pouvez par exemple utiliser [XChat dont l’installation est décrite dans nos pages](/articles/xchat-2-x-x-installation-simple-et-rapide-sous-windows/).

Ensuite, vous pouvez consulter le [guide de quelques commandes IRC bien pratiques](/articles/xchat-un-peu-plus-sur-irc-et-freenode/), qui vous permettront de mieux comprendre le fonctionnement d’IRC.
