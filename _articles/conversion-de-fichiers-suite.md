Ce second article vient en réponse à la majorité des questions que l’on m’a posé par mail, même si il ressemble étrangement au premier. Je vous signale également que je reste dans le cadre de Freelug, je veux bien apporté une aide pour les softs gratuits qui sont sur le site Ldraw.org ou les freewares diverses dont je vous indique les liens mais en aucun cas je ne répondrai sur le fonctionnement de 3DS MAX et autres softs 3D, il existe assez de sites sur ceux-là.

Les utilitaires de conversion 3D **gratuit** devenant de plus en plus rare,il faut parfois utiliser plusieurs programmes pour arriver à ses fins, je sais ça complique, mais bon c’est le résultat qui compte.

But : convertir un fichier ldraw (.dat) dans un format plus standard

| DE | A | SOFT A UTILISER | NOTES |
| --- | --- | --- | --- |
| DAT | 3DS | [**Leocad**](http://www.leocad.org/) | trop de faces ! |
| DAT | POV | [**Leocad**](http://www.leocad.org/) |  |
| DAT | POV | [**L2P**](http://www.el-lutzo.de/lego/l2p.html) | sous console DOS |
| DAT | OBJ | [**Leocad**](http://www.leocad.org/) |  |
| DAT | LWS | [**Ldraw2lws**](http://www.joern-thiemann.de/tools/ldraw2lws/) |  |
| OBJ | POV | [**GLView**](http://home.snafu.de/hg/) |  |
| OBJ | WRL | [**GLView**](http://home.snafu.de/hg/) |  |

[**GLView**](http://home.snafu.de/hg/) convertit également dans les formats suivants :

**Importe** : DXF, WRL, GEO, RAW, STL, OBJ

**Exporte** : WRL, POV, RAW, GEO, STL

voir également [**Crossroad**](http://home.europa.com/~keithr/crossroads/), mais il ne fonctionne pas sous tous les windows malheureusement, son développement s’étant arrêté en 1998.

**Importe** : 3DS, DXF, POV, RAW, COB, WRL, OBJ

**Exporte** : 3DS, DXF, POV, RAW, COB, WRL, OBJ, X
